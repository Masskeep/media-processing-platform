# Real-Time Distributed Media Processing Platform

A production-oriented distributed media processing platform built with React, Flask, Celery, Redis, PostgreSQL, FFmpeg, object storage, WebSockets, and Docker.

## Project Goals

- Large video uploads
- Chunked and resumable uploads
- Background media processing
- Parallel processing workers
- Real-time processing progress
- Audio extraction
- Waveform generation
- Cloud object storage
- Production-ready deployment
